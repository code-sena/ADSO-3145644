# Ejecución del Proyecto de Software

Este documento detalla rigurosamente las fases fundamentales de la ejecución de un proyecto de desarrollo de software, clasificadas en tres grandes bloques:

- **P: Planeación y ciclo de vida del software**
- **CP: Costos de Producción (hardware y software para el desarrollo)**
- **CPS: Costos del Proyecto como Servicio (para las partes interesadas)**

---

## I. P - Planeación y Ciclo de Vida del Software

Este bloque corresponde a la etapa inicial del desarrollo, centrada en comprender, diseñar y modelar la solución.

### 1. Diseñar Instrumentos

- Aplicación de metodologías como **Design Thinking** o priorización de tareas mediante **MoSCoW**.
- Se definen los instrumentos de recolección de requisitos, encuestas, entrevistas y herramientas colaborativas.

### 2. Aplicar Instrumentos

- Implementación práctica con usuarios finales, stakeholders y equipo técnico.
- Validación de necesidades reales para garantizar alineación con los objetivos del sistema.

### 3. Prototipo (Mockup)

- Creación de representaciones visuales y funcionales de la futura aplicación.
- Herramientas sugeridas: Figma, Adobe XD, Balsamiq.

### 4. Requerimientos Funcionales (RF)

- Listado completo de funcionalidades clave.
- Documentación técnica con formato estándar IEEE o similar.

### 5. Arquitectura

Diseño técnico que servirá de base para la construcción del sistema.

- **Modelado UML**:
  - Diagrama de Casos de Uso
  - Diagrama de Clases
  - Diagrama de Dominio
  - Diagrama de Paquetes
  - Diagrama de Secuencia
- **Diseño de Interfaces**:
  - Web
  - Aplicación de escritorio
  - Aplicación móvil (responsive/adaptativa)

---

## II. CP - Costos de Producción (Desarrollo del Software)

Esta sección abarca los costos estimados para permitir la construcción del sistema.

### 1. Personal

- Costos asociados a perfiles como analistas, desarrolladores, diseñadores, testers y DevOps.
- Se estiman tiempos y salarios en función del alcance del proyecto.

### 2. Equipos

- Hardware requerido: estaciones de trabajo, laptops, dispositivos móviles para pruebas.
- Costos por renovación o adquisición de nuevos equipos.

### 3. Licencias

- Software necesario para desarrollo:
  - IDEs (IntelliJ, Visual Studio, etc.)
  - Herramientas de diseño
  - Bases de datos (licencias comerciales si aplica)

### 4. Tools

- Costos por herramientas de integración continua, control de versiones y documentación:
  - GitHub, GitLab, Jenkins, Notion, Confluence.

### 5. Redes y Servidores

- Infraestructura de red interna y servidores para entornos de prueba (staging) y desarrollo.

---

## III. CPS - Costos del Proyecto como Servicio (Entrega y Operación)

Estos son los costos finales que se consideran una vez el software esté terminado y disponible para entrega o comercialización.

### 1. Ficha Técnica del Software

- Documento formal que describe:
  - Funcionalidades finales
  - Arquitectura implementada
  - Dependencias
  - Requisitos mínimos

### 2. Costo de Licenciamiento

- Precio por usuario, por módulo o por instalación.
- Consideraciones de tipo de licencia (perpetua, anual, por consumo).

### 3. Costo de Infraestructura de DevOps

- Servicios en la nube, pipelines de CI/CD, monitoreo y automatización.
- Plataformas como AWS, Azure, GCP, Vercel o Heroku.

### 4. Costo de Soporte

- Contratación de personal para brindar mantenimiento correctivo, adaptativo y evolutivo.
- Incluye SLA definidos según contrato.

### 5. Temporalidad de la Licencia

- Duración de las licencias ofrecidas al cliente final (mensual, anual, perpetua).

### 6. Proceso de Capacitación / Coste

- Entrenamiento a usuarios finales y equipos de TI.
- Puede incluir:
  - Manuales de usuario
  - Videotutoriales
  - Talleres virtuales/presenciales

---

## Conclusión

Cada bloque (P, CP, CPS) representa un momento estratégico en la ejecución de un proyecto de software. Una planeación rigurosa permite calcular de forma precisa los recursos, plazos y entregables, garantizando así la viabilidad técnica y financiera del producto final.
