# Ficha Técnica de Hardware y Software

## 1. Descripción General
Aplicación para llevar el control de las tareas diarias de una persona, permitiendo registrar categorías, actividades y clientes, así como consultar el estado de las tareas.

---

## 2. Requerimientos de Hardware

| Componente         | Requerimiento Mínimo         | Recomendado                |
|--------------------|------------------------------|----------------------------|
| Procesador         | Intel Core i3 o equivalente  | Intel Core i5/i7 o superior|
| Memoria RAM        | 4 GB                         | 8 GB o más                 |
| Almacenamiento     | 500 MB libres                | 2 GB libres                |
| Resolución pantalla| 1366x768                     | 1920x1080                  |
| Conectividad       | Acceso a Internet            | Acceso a Internet          |

---

## 3. Requerimientos de Software

| Componente         | Versión Mínima               | Recomendado                |
|--------------------|------------------------------|----------------------------|
| Sistema Operativo  | Windows 10 / Linux / macOS   | Última versión estable     |
| Navegador Web      | Chrome 90+, Firefox 88+, Edge| Última versión             |
| Node.js            | 16.x                         | 18.x o superior            |
| NPM                | 7.x                          | 8.x o superior             |
| Base de Datos      | SQLite / MySQL / PostgreSQL  | PostgreSQL 13+             |
| Editor de Código   | Visual Studio Code           | Visual Studio Code         |

---

## 4. Dependencias y Herramientas
- Framework: Express.js (Node.js)
- Librerías: body-parser, cors, dotenv
- Frontend: HTML5, CSS3, JavaScript
- Control de versiones: Git
- Herramientas DevOps: Docker (opcional), GitHub Actions (opcional)

---

## 5. Observaciones
- La aplicación puede desplegarse localmente o en la nube (Heroku, Vercel, AWS, etc.).
- Se recomienda realizar copias de seguridad periódicas de la base de datos.
- Para ambientes productivos, considerar HTTPS y autenticación robusta.
