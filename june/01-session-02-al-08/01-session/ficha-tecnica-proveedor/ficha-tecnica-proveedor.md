# Ficha Técnica del Producto: Sistema Gestor de Tareas

## 1. Descripción
Aplicación web para el control y gestión de tareas diarias, permitiendo registrar categorías, actividades y clientes, así como consultar el estado de las tareas por usuario.

## 2. Características y Funciones
- Registro y gestión de clientes (personas): tipo y número de documento, nombre, apellidos, edad, correo electrónico, usuario y contraseña.
- Registro y gestión de categorías: código, nombre, descripción, estado.
- Registro y gestión de tareas: código, nombre, descripción, estado, fecha de inicio y fin, asociación a categoría.
- Consulta de tareas por usuario y estado (agendada, cumplida, cancelada).
- Validación para evitar registros duplicados.

## 3. Especificaciones Técnicas
| Característica         | Detalle                                                        |
|-----------------------|----------------------------------------------------------------|
| Tipo de producto      | Aplicación web                                                 |
| Lenguaje principal    | JavaScript (Node.js, Express, HTML5, CSS3, JS)                 |
| Base de datos         | PostgreSQL / MySQL / SQLite                                    |
| Arquitectura          | Cliente-Servidor (MVC)                                         |
| Acceso                | Navegador web moderno                                          |
| Seguridad             | Autenticación por usuario y contraseña, validación de datos     |
| Despliegue            | Local o en la nube (Heroku, Vercel, AWS, etc.)                 |

## 4. Requerimientos de Hardware y Software
- Procesador: Intel Core i3 o superior
- RAM: 4 GB mínimo (8 GB recomendado)
- Almacenamiento: 500 MB libres mínimo
- Sistema Operativo: Windows 10+, Linux, macOS
- Navegador: Chrome, Firefox, Edge (última versión)
- Node.js 16+ y NPM 7+

## 5. Observaciones
- Cumple con normas básicas de presentación de documentos.
- Permite la gestión eficiente de tareas y usuarios.
- Escalable y adaptable a diferentes entornos de despliegue.
- Se recomienda realizar respaldos periódicos de la base de datos.
