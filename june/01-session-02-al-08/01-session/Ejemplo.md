Creaer un aplicación para llevar el control de las tareas que una persona debe llevar día a día en sus actividades. 

1. Registrar categorias
2. Registrar actividades
3. Registrar clientes

==================
Establecer los requerimientos funcionales de la aplicación.
*
*
1. RF: Realizar la gestión de los datos básicos de un cliente (persona).

- Capturar el tipo documento, nombre, apellidos, edad, correo electrónico
- No se permiten registros duplicados
- a cada usuario se le asigna un usuario y una contraseña 

2. RF: Realizar la gestión de los datos que e van a guardar de una categoría. 

- Capurar los datos código de la categoiria, nombre, descripción y un estado. 
- No se permiten registro ducplicados 
- Una categoría puede vincular a muchas tareas, el propopoisto es agrupar tareas. 

3. FR: Realizar la gestión de los datos de las tareas.

- Capturar el código de la tarea, el nombre, la descripción, el estado, fecha de inicio y fecha de fin 
- Se puede asociar cada tarea a una única categoría. 


4. RF mostrar la lista de tareas por usuario, y su estado, agendada, cumplida o cancelada.
