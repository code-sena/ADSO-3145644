# Historia de Usuario Backend - HU-05

Como administrador del sistema,
quiero generar facturas de venta y actualizar automáticamente el inventario
de forma que las ventas queden registradas y el stock de productos se mantenga actualizado.

---

## Definición de Ready (DoR)
- La historia está claramente entendida por el equipo.
- Se han definido los campos y reglas de negocio para facturación.
- Se cuenta con acceso a la base de datos y modelos necesarios.
- Los endpoints requeridos están especificados.
- Los criterios de aceptación están definidos.

## Definición de Done (DoD)
- El backend permite generar facturas y asociar productos y clientes.
- Se actualiza automáticamente el inventario tras la venta.
- Se valida la disponibilidad de stock antes de facturar.
- Se gestionan errores y mensajes apropiados.
- Se han realizado pruebas unitarias y de integración.
- El código está documentado y versionado.
- Se ha realizado code review.
- La funcionalidad está desplegada en el entorno de pruebas.
