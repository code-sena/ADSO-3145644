# Historia de Usuario Backend - HU-01

Como administrador del sistema,
quiero registrar nuevos clientes en la base de datos
de forma que pueda identificar y gestionar a los clientes para futuras ventas y facturación.

---

## Definición de Ready (DoR)
- La historia está claramente redactada y entendida por el equipo.
- Se cuenta con los campos requeridos para el registro de clientes.
- Se han identificado las validaciones necesarias (unicidad, formatos, etc.).
- Se dispone de acceso a la base de datos.
- Los criterios de aceptación están definidos.

## Definición de Done (DoD)
- El backend permite registrar clientes con todos los campos requeridos.
- Se valida la unicidad del documento de identidad.
- Se gestionan errores y mensajes apropiados.
- Se han realizado pruebas unitarias y de integración.
- El código está documentado y versionado.
- Se ha realizado code review.
- La funcionalidad está desplegada en el entorno de pruebas.
