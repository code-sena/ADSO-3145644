# Definición del Problema

## Descripción

Pepito Perez tiene una tienda y necesita una solución para llevar el control de las ventas de manera eficiente. Actualmente, el proceso de registro de ventas es manual, lo que genera errores y pérdida de tiempo.

## Alcance del Proyecto

El proyecto consiste en crear una aplicación web que permita:

- Registrar ventas diarias.
- Generar reportes de ventas.
- Gestionar el inventario de productos.
- Consultar historial de ventas.
- Administrar usuarios con diferentes niveles de acceso.

## Objetivos

- **Objetivo General**: Desarrollar una aplicación web para optimizar el control de ventas de la tienda de Pepito Perez en un periodo de tres meses.
- **Objetivos Específicos**:
  - Implementar un sistema de registro de ventas.
  - Crear módulos para la generación de reportes.
  - Desarrollar funcionalidades para la gestión de inventario.
  - Integrar un sistema de historial de ventas.
  - Configurar un sistema de administración de usuarios.

## Requisitos

- La aplicación debe ser accesible desde cualquier dispositivo con conexión a internet.
- Debe contar con una interfaz amigable y fácil de usar.
- El sistema debe garantizar la seguridad de los datos.

## Plazo

El proyecto debe completarse en un periodo de tres meses.
