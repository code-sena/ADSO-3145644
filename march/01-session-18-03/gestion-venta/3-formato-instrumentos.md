# Instrumentos

## Encuesta

### Objetivo
Recopilar información sobre las necesidades y expectativas de los usuarios respecto a la aplicación web para el control de ventas.

### Preguntas
1. ¿Con qué frecuencia realiza el registro de ventas en su tienda?
   - [ ] Diariamente
   - [ ] Semanalmente
   - [ ] Mensualmente
   - [ ] Ocasionalmente

2. ¿Qué tan importante es para usted generar reportes de ventas?
   - [ ] Muy importante
   - [ ] Importante
   - [ ] Poco importante
   - [ ] No es importante

3. ¿Con qué frecuencia necesita consultar el historial de ventas?
   - [ ] Diariamente
   - [ ] Semanalmente
   - [ ] Mensualmente
   - [ ] Ocasionalmente

4. ¿Qué tan útil sería para usted recibir notificaciones sobre niveles bajos de inventario?
   - [ ] Muy útil
   - [ ] Útil
   - [ ] Poco útil
   - [ ] No es útil

5. ¿Qué nivel de acceso deberían tener los diferentes usuarios de la aplicación?
   - [ ] Administrador
   - [ ] Vendedor
   - [ ] Consultor
   - [ ] Otro: __________

## Formato de Lista de Chequeo

### Objetivo
Verificar que la aplicación web cumpla con los requisitos y funcionalidades definidas.

### Lista de Chequeo
- [ ] El sistema permite el registro de ventas diarias.
- [ ] La aplicación genera reporte de ventas detallados.
- [ ] El inventario de productos se puede gestionar eficientemente.
- [ ] Es posible consultar el historial de ventas.
- [ ] La administración de usuarios con diferentes niveles de acceso está implementada.
- [ ] Se reciben notificaciones y alertas sobre niveles bajos de inventario.
- [ ] Los datos están protegidos contra accesos no autorizados.
- [ ] La interfaz es amigable e intuitiva para los usuarios.
